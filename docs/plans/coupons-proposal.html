One page, three decisions. Most of the machinery already exists from the July money-model build; nothing here is a new system.

The one place they live

This is NOT the onboarding wizard, and Lij never sees it. The workbook stays the only owner-facing surface, and it already collects his codes. This page is about the two things AFTER the workbook: where his answers are stored, and the staff-only screen where BAM pushes a code live in Stripe.

Storage: the academy's offer record in the database already holds a discount-codes list, the workbook writes into it, and the July build can push a code to Stripe with its applies-to list enforced natively. The proposal keeps that as the ONLY home and gives each code a state, instead of codes being half-real.

#QuestionProposed answer
